Возможности

Всё необходимое
для инвентаризации

Приложение охватывает полный цикл: от создания карточки предмета до формирования итогового отчёта.

QR-коды

Генерация уникального QR-кода для каждого предмета. Сохранение в галерею или мгновенный скан камерой.

Инвентаризация

Создание сессий по выбранным комнатам. Статус каждого предмета: найден, отсутствует или не в той комнате.

Отчёты

Календарный обзор всех сессий. Детальный отчёт по каждой проверке с разбивкой по комнатам и статусам.

Поиск

Мгновенный поиск по названию, инвентарному номеру или комнате. Фильтрация и сортировка списка.

Офлайн

Все данные хранятся локально на устройстве через Hive. Работает без подключения к интернету.

Экспорт данных

Выгрузка справочников: этажи, комнаты, типы локаций. Готово к интеграции с учётными системами.

Демо

Интерфейс приложения

Простой и понятный дизайн на основе Material Design 3 с корпоративной цветовой схемой.
